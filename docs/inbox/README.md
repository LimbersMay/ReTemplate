# Material de partida

Lo que llega en bruto: el documento de requisitos, los mocks, capturas, notas. **No se edita**: es la
entrada de `/sdd:discover`, que lo reparte en `product.md`, `requirements.md`, `domain.md`,
`architecture.md` y `ux.md`. Si llega material nuevo, se añade aquí con fecha y se vuelve a pasar
`/sdd:discover` solo para lo nuevo.
